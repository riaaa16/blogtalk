This is a small, static blog built with Next.js and published on GitHub Pages.

Each blog post is a MD file written by Llama-3.2-3B. The AI integration is ran prompted locally, allowing the user to prompt an LLM to modify blog posts via a Python CLI or a web interface. The app turns the response into a properly formatted Markdown post, saves it into the site content folder, and can optionally commit and push the changes using a GitHub Personal Access Token.
